## Documentation boundary

This index and the Studio navigation use repository-owned references that remain available when the application is copied or cloned. Local project planning, decision history, QA records and chronological changelogs live outside the application and are not public wiki navigation targets. Current implementation contracts belong in the public guides above; local history is not required to run or validate the application.
