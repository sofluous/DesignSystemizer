# Approved semantic icons

Load js/icon-approved.js then js/icon-runtime.js. Use <span data-ds-icon="action.search"></span> inside a button with visible text or an aria-label. Icons are decorative; label the control. Call DesignSystemIcons.render(container) after adding content. Unknown aliases are empty and marked data-ds-icon-state="missing". Individual SVGs and the manifest are included for other frameworks. No network request is required. Only approved assets ship; candidate selections and browser defaults do not. Keep licenses with copied assets.
